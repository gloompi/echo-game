# ECHO

**The Seeker sees 3 seconds in the past.**

An asymmetric multiplayer arena game. Hiders are visible, but seekers receive everyone else's poses three seconds late. Your own movement is immediate. Shots hit the present, not historical hitboxes.

The first playable browser alpha is being implemented with Three.js and a server-authoritative Node.js simulation. Character art direction: blocky striped hiders, armored seekers with orange toy blasters, and a cyan/magenta neon arena.
